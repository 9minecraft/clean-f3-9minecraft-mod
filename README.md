# Clean F3 — A Tidier, Cleaner Debug Screen

Clean F3 9minecraft Mod cleans up your debug screen by removing unneeded text lines and clutter. When you press the debug key in standard Minecraft, half of your display gets covered in hardware stats, memory graphs, and block tags that you rarely need during survival gameplay. This mod strips away the noisy background information so you only see essential details like your coordinates, chunk data, facing direction, and current biome.

## What this build is

An unofficial rebuild of **tyrannus**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
